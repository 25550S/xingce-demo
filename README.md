# 行测成长记

单机学习用的行测练习页：刷题、错题重做、组卷和进步曲线都在浏览器里完成。个人数据（错题本、练习记录、备份）只保存在你自己的浏览器里，或由你导出的文件里，不会出现在本仓库。

## 打开方式

- 手机（当前可用）：用浏览器打开  
  [https://htmlpreview.github.io/?https://github.com/25550S/xingce-demo/blob/main/index.html](https://htmlpreview.github.io/?https://github.com/25550S/xingce-demo/blob/main/index.html)
- 电脑：同一网址，或打开 OneDrive「行测成长记」文件夹里的 `行测成长记.html`（不需要联网也能用已导入的题）。

正式地址 [https://25550S.github.io/xingce-demo/](https://25550S.github.io/xingce-demo/) 需在仓库 Settings → Pages 将源设为 GitHub Actions 后才会生效（已放好工作流）。

用网页打开时，会自动加载本仓库里的 1 期 12 套题库（含资料材料和答案）。也可以继续用原来的文件夹 / 文件导入作为补充。

## 云端自动同步（电脑 ⇄ 手机）

用你自己 GitHub 账号下的私有空间（Private Gist）在电脑和手机之间自动同步进度。公开网页和本仓库不会出现你的错题本。

1. 在「设置 → 云端自动同步」点「打开 GitHub 生成同步钥匙」。页面会自动勾选 gist 权限，Expiration 建议选 No expiration，点底部 Generate token，复制生成的钥匙。
2. 把钥匙粘贴到「同步钥匙」框，点「连接并开启自动同步」。电脑和手机都要做一次（用同一把钥匙）。
3. 连上以后，一边刷题或改数据，另一边打开页面（或点「立即同步」）就会自动对齐。

同步钥匙只存在这台设备的这个浏览器里，不会写进本仓库、普通备份或「发给助手」的文件。「断开同步」只是忘掉这台设备上的钥匙，不会删除本机数据或云端备份。如果同步后发现本机记录不见了，可在设置里点「恢复同步前的数据」。请同时保留「导出备份」。

本仓库只发布应用和题库，不含任何人的错题本或备份。
