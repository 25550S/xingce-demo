使用说明

1. 打开

  • 在 OneDrive 的「行测成长记」文件夹里双击「行测成长记.html」，用 Chrome 或 Edge 打开。不需要安装，也不需要联网。
  • 每次都用同一个浏览器打开，数据才会在。

2. 导入错题本

  • 打开「错题统计」，先选模块（言语理解 / 数量关系 / 逻辑判断 / 资料分析），再选 Excel 文件或整个文件夹。
  • 错题本的「来源」写成 名称（题号），如「套题3（52）」。名称里有「片段刷题」「600题」「专项」的算专项练习，只在错题统计里看，不影响五维分数；其余算套卷。
  • 错题本更新后重新导入即可，同名文件会覆盖。同一份错题本不要用两个文件名重复导入，否则会重复计数。
  • 统计的考点不合适时，在文件列表里的「考点列」下拉框换一列。

3. 登记套卷

  • 打开「套卷」。「错题本中尚未登记的套卷」会列出错题本里出现过、但还没登记的套卷，点「登记这套卷」即可。
  • 套卷名称要和错题本来源里的名称完全一致（如「套题3」），才能自动算对题数。
  • 导入了错题本的模块，对题数自动算：题数 − 这套卷在该模块的错题数。没有错题本的模块（如政治理论、常识判断）要勾选「手动」自己填。
  • 点套卷记录里的「详情」，可以看这套卷的全部错题、错得最多的考点和错因。

4. 错题重做

  • 用网页（手机或电脑）打开时，1 期 12 套卷的题目和答案会自动加载，不用导入题库。
  • 从 OneDrive 双击打开这个 html 文件时：打开「错题重做」，点「选择题库文件夹」，选「1/题库」文件夹（试卷 txt 和答案汇总会一起导入）。只需做一次，题目保存在本浏览器里。1 期 12 套卷的答案已经内置。
  • 以后如果有新的套卷，仍可用「选择题库文件夹」补充。数据只存在你正在用的这个浏览器里，换手机或换浏览器后需要重新导入错题本，建议定期备份。
  • 在套卷详情里点「重做本卷全部错题」，或选一个模块「重做该模块全部套卷错题」。也可以在「错题重做」页按套卷、模块开始。
  • 做题时一屏一题，点选项作答，右边答题卡可以跳题。每题和总用时自动计时，回到同一题会接着计时。「查看答案」会显示正确选项和你的复盘笔记。
  • 做完点「交卷」，结果页里你选对的选项是绿色；选错的是红色，正确答案标绿色；没作答的会标出来。每次重做都会保存在「重做记录」里。
  • 重做成绩不影响套卷总分和对题数。同一道题连续 2 次重做都做对、并且没有看答案，自动算「已掌握」；也可以点题目旁的「标为已掌握」手动标记（再点一次取消）。手动标为掌握后如果重做又做错，会自动取消。
  • 设置里「已掌握的错题不计入错题扣分」默认打开：已掌握的错题不再参与五维的薄弱考点扣分（基础正确率分不变）。关掉后五维完全不受重做影响。
  • 含图的题会提示去看原 PDF 的第几页。没有导入题目的题会显示「题目未导入」，仍可以按 A–D 作答。

今日待重做

  • 总览的「今日待重做」按错题本里的日期，在第 3 天、第 7 天各提醒一次；过了日期还没做的显示为逾期。点「开始重做」一次做完，作答过的题提醒就算完成。
  • 错题统计下方的「重做表现」按考点列出重做次数、做对次数、正确率和平均用时，点表头可以排序。

5. 标记与一键组卷

  • 在重做页面、结果页或套卷详情里，点 ☆ 收藏，点「易混」「再看」等标签标记，点「+」可以加自定义标签。
  • 「一键组卷」可以按模块、考点、错因、标记筛选，随机抽 N 道错题开始重做，默认排除已掌握的题。

6. 本周重点与错因提示

  • 总览的「本周重点」列出近 30 天套卷错题里最常见的 2–3 个错因。「通用技巧」是程序内置的固定提示，可在设置的「错因技巧表」里修改；「你的笔记」摘自你自己的复盘笔记。
  • 错题统计里点任意一个考点，可以展开看它的高频错因和相关笔记。

7. 发给助手 / 复制摘要

  • 总览右上角的「发给助手」会下载「给助手的数据_日期.json」。把它放到 OneDrive 的「1」文件夹，然后对助手说「看一下我的数据」。
  • 「复制摘要」会把一段简短的文字摘要复制下来，可以直接粘贴到聊天里。

8. 分数怎么算

    9. 备份

    • 超过 7 天没备份，总览顶部会出现提醒。点「立即导出备份」会下载「行测成长记备份_日期.json」，把这个文件从「下载」文件夹拖进 OneDrive 的「行测成长记」文件夹即可。
    • 换电脑或换手机时，在「设置」点「导入备份」选这个文件即可恢复。备份不含题库题目：用网页打开会自动再加载 1 期 12 套；用文件打开时请再导入一次「1/题库」文件夹。

    10. 云端自动同步（电脑 ⇄ 手机）

    • 在「设置 → 云端自动同步」点「打开 GitHub 生成同步钥匙」。页面会自动勾选 gist 权限，Expiration 建议选 No expiration，点底部 Generate token，复制生成的钥匙。
    • 把钥匙粘贴到「同步钥匙」框，点「连接并开启自动同步」。电脑和手机都要做一次（用同一把钥匙）。连上以后，一边刷题或改数据，另一边打开页面（或点「立即同步」）就会自动对齐。
    • 数据保存在你自己 GitHub 账号下的私有空间（Private Gist）里，公开网页和仓库不会出现你的错题本。同步钥匙只存在这台设备的这个浏览器里，不会写进普通备份，也不会写进「发给助手」的文件。
    • 「断开同步」只是忘掉这台设备上保存的钥匙，不会删除本机数据，也不会删除云端备份。重新粘贴同一把钥匙即可继续同步。
    • 请同时保留「导出备份」。同步需要联网；用文件打开（file://）也可以，只要设备能访问 GitHub。
    • 如果同步后发现本机刚做的记录不见了，到「设置 → 云端自动同步」点「恢复同步前的数据」。这里会列出同步覆盖本机前自动保存的副本（最多 3 份），恢复后再和云端合并，两边的重做记录都会保留。
